Answer:
Rewrite it as `(q → p) ∧ (r → q) ∧ (p → r)`. These three implications form a cycle. If `p, q, r` are all true, then each implication is true. If `p, q, r` are all false, then each implication is also true. If they are not all the same, then somewhere in the cycle a true statement points to a false one, so one implication becomes false. Therefore the whole conjunction is true exactly when `p, q, r` have the same truth value.
